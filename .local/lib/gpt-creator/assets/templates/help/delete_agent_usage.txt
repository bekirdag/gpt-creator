Usage: gpt-creator delete-agent --name NAME [--project PATH] [--force] [--json]

Remove an agent from the tasks database.

Behaviour:
  Default (without --force) performs a soft delete by setting `is_active = 0`
  so the record can be reinstated later.
  --force performs a hard delete (row removed permanently).

Flags:
  --name NAME     Agent identifier to delete (required).
  --project PATH  Project root (defaults to current directory).
  --force         Hard delete.
  --json          Emit a JSON acknowledgement instead of a status message.
