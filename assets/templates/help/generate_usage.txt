gpt-creator generate — code generation orchestrator

USAGE
  gpt-creator generate [all|api|web|admin] [options]

OPTIONS
  -m, --model <name>        Adapter model (default: ${GENERATE_USAGE_CODEX_MODEL}); when adapter=codex, maps to CODEX_MODEL
      --agent <name>        Resolve the model from a stored agent persona (fallbacks to raw model id when missing)
  --codex-cmd <cmd>         Codex CLI (default: ${GENERATE_USAGE_CODEX_CMD}; used only when adapter=codex)
  -y, --yes                 Non-interactive; auto-accept prompts
  -n, --dry-run             Plan only; do not call the adapter
  --skip-install            Skip package install/build steps
  --out-root <dir>          Root output (default: ${GENERATE_USAGE_OUT_ROOT})
  -h, --help                Show this help

EXAMPLES
  gpt-creator generate all -y
  gpt-creator generate api  --model gpt-5-high
  gpt-creator generate web  --out-root ./apps
  gpt-creator generate admin -n
