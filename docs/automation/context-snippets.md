# Keeping Prompt Context Lean

Two helpers keep `work-on-tasks` prompts slim by trimming documentation excerpts and deduplicating boilerplate:

- `tools/scripts/python/render_context_snippet.py` — extracts bounded sections from manifest/catalog inputs and writes a compact snippet file.
- `tools/scripts/python/compose_sections.py` — merges multiple prompt sections while emitting the "System"/"Preamble" block only once and removing duplicate text.

Use them together whenever a task needs large doc/index references or multiple prompt fragments.

## render_context_snippet.py workflow

1. Build or locate a manifest file that lists the docs you need (often generated by `create-jira-tasks` or binder tooling).
2. Run `render_context_snippet.py` with the manifest path, the desired output snippet path, and optional catalog/library paths.
3. Reference the generated snippet file in your prompt or attach it via `gpt-creator show-file`.

Key arguments:

```
python3 tools/scripts/python/render_context_snippet.py \
  --manifest .gpt-creator/staging/plan/work/doc-manifest.txt \
  --output .gpt-creator/staging/context/doc-snippet.md \
  --catalog .gpt-creator/staging/plan/work/doc-catalog.json \
  --library .gpt-creator/staging/doc-library.md \
  --index .gpt-creator/staging/doc-index.md
```

- Manifest entries drive which docs get excerpted.
- Optional catalog/library/index paths let the script pull headings and truncated sections without loading entire files.
- Environment variables (`CJT_*`) control line/char limits so you can tune snippet sizes per run.

## compose_sections.py workflow

Import the helper inside Python tooling or a quick REPL whenever you need to merge sections:

```python
from scripts.python.compose_sections import emit_preamble_once, dedupe_and_coalesce, format_sections

sections = [
    ("System", "You are Codex"),
    ("System", "You are Codex"),
    ("Context", "Doc snippet A"),
    ("Context", "Doc snippet A"),
    ("Plan", "Steps here"),
]

clean = format_sections(dedupe_and_coalesce(emit_preamble_once(sections)))
```

`emit_preamble_once` ensures only the first Preamble/System block stays. `dedupe_and_coalesce` merges duplicate headings, trims whitespace, and collapses repeated bodies. `format_sections` prints Markdown-ready text with `## Heading` separators.

## Why this matters for token usage

- Trimming doc snippets before they enter the prompt removes thousands of irrelevant characters that would otherwise count toward the prompt token budget.
- Deduping sections prevents repeated "System"/"Focus" paragraphs from inflating prompts when multiple helpers contribute fragments.
- Lean prompts reduce the chance of hitting hard LLM limits, which keeps the patch/work stages shorter and less error-prone.

Whenever you notice prompts carrying entire doc-index files or repeated boilerplate, regenerate the snippet via `render_context_snippet.py` and run the final section list through `compose_sections.py` (or its exported helper functions) before handing off to Codex.
