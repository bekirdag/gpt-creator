# create-doc-placeholder.sh

Create a timestamped documentation stub so Codex can patch a focused section instead of emitting a whole file during work-on-tasks.

## Usage

```
scripts/create-doc-placeholder.sh docs/delivery/foo/plan.md \
  --owner "Release PM" \
  --summary "Escalation plan for Foo release" \
  --date 2025-11-18
```

- `--owner` (required) becomes the default assignee in the template.
- `--summary` seeds the TODO paragraph so the agent understands what belongs there.
- `--date` overrides the auto-generated UTC date when you need to backdate a placeholder.

The script clones `scripts/python/render_doc_placeholder.py` into `.gpt-creator/shims/python/` (if needed) and invokes it with metadata so every placeholder includes:

1. Ownership block (team/role, ISO timestamp, summary).
2. Compact CSV row for downstream tooling.
3. Timestamp-aware headline so diffs make sense across runs.

Templates live under `assets/templates/doc_placeholders/` and are picked by file extension. If the target file already exists, nothing is overwritten.

Tip: run this command before touching large specs; it gives Codex a skeleton to edit and keeps token usage low.
