# render_context_snippet.py

Build a trimmed documentation snippet so prompts only include the required binder slices.

## Usage

```
python3 scripts/python/render_context_snippet.py \
  --manifest .gpt-creator/staging/plan/work/doc-manifest.txt \
  --output .gpt-creator/staging/context/doc-snippet.md \
  --catalog .gpt-creator/staging/plan/work/doc-catalog.json \
  --library .gpt-creator/staging/doc-library.md \
  --index .gpt-creator/staging/doc-index.md
```

Flags:

- `--manifest`: tab-delimited manifest generated by binder tooling (required).
- `--output`: destination snippet file (required).
- `--catalog`: optional JSON catalog for metadata lookups.
- `--library`: optional doc-library file (truncated per env vars).
- `--index`: optional doc-index file.

Tune snippet size using `CJT_DOC_*` environment variables (lines, char limits, etc.). Use this before passing context into prompts—Codex then references the snippet instead of raw docs, keeping prompt tokens low.
